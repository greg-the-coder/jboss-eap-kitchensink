QUICK START
-----------
Option 1: Docker Compose (Recommended)
  $ cp .env.example .env
  $ docker-compose up --build
  → Open http://localhost:3000

Option 2: Local Development
  Terminal 1:
    $ cd kitchensink
    $ ./mvnw spring-boot:run -Dspring-boot.run.profiles=dev
  Terminal 2:
    $ cd frontend
    $ npm install && npm run dev
  → Open http://localhost:3000
